### 質問の目的

## Q04 — クラウド移行の可能性と懸念点

### 質問

現在オンプレミスで運用されていますが、
クラウドを利用する選択肢はありますか。

また、クラウド移行を妨げている理由や
懸念点についてお聞かせいただけますか。

### 質問の目的

- クラウド移行に対する経営陣の意向を確認する
- 移行を妨げている要因を特定する
- 技術的・経営的な制約条件を把握する

### クライアントの回答

経営陣はクラウド移行に前向きであり、
AWSとAzureを検討候補としている。

ただし、具体的なサービス調査や
費用試算は実施していない。

#### 1. セキュリティ

- 顧客企業の機密情報・個人情報を扱う
- 一部の顧客との契約で国内データ保管が必須
- 現行環境と同等以上のセキュリティを希望

#### 2. コスト

- クラウド利用料の変動に対する懸念
- 顧客数増加に伴う将来的な費用が不明

#### 3. 移行時の制約・希望条件

| 項目 | 希望条件 |
|---|---|
| 計画停止時間 | 最大2時間 |
| 作業時間帯 | 土日・深夜 |
| データ損失 | 不可 |
| 移行期間 | 6〜12か月以内 |

#### 4. 社内の技術力

| スキル | 経験者数 |
|---|---|
| Linux | 3人 |
| ネットワーク | 2人 |
| PostgreSQL | 2人 |
| AWS基礎 | 1人 |
| Azure基礎 | 0人 |
| 本番クラウド運用 | 0人 |

#### 5. 既存システムとの互換性

- オンプレミスを前提としたアプリケーション
- 移行に必要な改修範囲が不明

#### 6. ベンダーロックイン

- 特定のクラウド事業者への依存
- 将来的な料金上昇への懸念
- 他事業者への移行難易度

#### 経営陣の方針

全面的なクラウド移行に限定せず、
部分移行やオンプレミスの改善も検討する。

### 分析・気づき

- クラウド移行を妨げている要因は、
  技術的な実現可能性だけでなく、
  経営判断に必要な情報の不足にもあると考えられる。
- AWS・Azureの経験者が少なく、
  移行後の運用体制や人材育成も検討する必要がある。
- 顧客情報を扱うため、セキュリティと
  データの国内保管を重視する必要がある。
- 経営陣がクラウド移行に前向きであるため、
  複数のインフラ構成を柔軟に提案できる。

### 追加確認事項

- 現在のITインフラの年間運用費用
- クラウド移行に充てられる予算
- 現在のセキュリティ対策と契約上の要件
- 外部の技術支援や人材教育の利用可否
